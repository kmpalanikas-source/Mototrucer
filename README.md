# Moto Tracker 300+

Android εφαρμογή στα Ελληνικά για αναζήτηση, τεχνικά χαρακτηριστικά, σύγκριση και βασικό οδηγό αγοράς μοτοσυκλετών.

## Δημιουργία APK
Κάθε push στο `main` ή χειροκίνητη εκτέλεση του workflow **Build Android APK** δημιουργεί debug APK.

Στο GitHub: **Actions → Build Android APK → τελευταίο επιτυχές run → Artifacts → Moto-Tracker-300-Plus-APK**.

## Τεχνολογία
- Kotlin
- Jetpack Compose / Material 3
- minSdk 24 (Android 7.0)
- compileSdk 35

Τα τεχνικά στοιχεία και οι καταναλώσεις είναι ενδεικτικά. Πριν από αγορά απαιτείται επιβεβαίωση ανά έτος και έκδοση.
